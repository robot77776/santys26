# Тайный Санта 2026

Готовый проект сайта для новогодней игры на Next.js + Supabase + Vercel.

## Возможности
- Общая ссылка на регистрацию.
- Поля: имя и фамилия (обязательно), пожелания, чего не дарить, дополнительные пожелания (необязательно).
- Телефон и email не собираются.
- Личная секретная ссылка участника.
- Главная страница показывает актуальное количество зарегистрированных участников (обновление каждые 30 секунд).
- Админ-панель: список участников, закрытие регистрации, запуск жеребьёвки.
- Жеребьёвка без самоназначений и повторяющихся получателей.
- Организатор не видит пары через интерфейс.
- Бюджет подарка: 500 рублей.

## 1. Создать Supabase
1. Создайте новый проект Supabase.
2. Откройте SQL Editor → New query.
3. Скопируйте весь файл `supabase/schema.sql` и нажмите Run.
4. Откройте Project Settings → API.
5. Скопируйте Project URL и `service_role` key (секретный ключ).

## 2. Подготовить переменные окружения
Скопируйте `.env.example` в `.env.local` и заполните:
- `NEXT_PUBLIC_SUPABASE_URL` — Project URL.
- `SUPABASE_SERVICE_ROLE_KEY` — service_role key.
- `ADMIN_PASSWORD` — придумайте длинный уникальный пароль администратора.
- `SESSION_SECRET` — отдельная случайная строка минимум 32 символа.
- `NEXT_PUBLIC_SITE_URL` — URL сайта Vercel; локально `http://localhost:3000`.

Не публикуйте `.env.local`, `service_role` key, `ADMIN_PASSWORD` и `SESSION_SECRET` в GitHub.

## 3. Загрузить в GitHub
Загрузите содержимое этой папки в корень нового GitHub-репозитория. Файл `.env.local` не загружайте.

## 4. Развернуть на Vercel
1. Импортируйте репозиторий в Vercel.
2. Framework: Next.js.
3. В Settings → Environment Variables добавьте все пять переменных из `.env.example`.
4. Для `NEXT_PUBLIC_SITE_URL` укажите итоговый адрес сайта, например `https://your-name.vercel.app`.
5. Нажмите Deploy. После изменения переменных сделайте Redeploy.

## 5. Проверка
1. Откройте главную страницу сайта.
2. Зарегистрируйте тестового участника.
3. Сохраните личную ссылку, которую сайт покажет после регистрации.
4. Откройте `/admin`, введите `ADMIN_PASSWORD`.
5. Проверьте список участников.
6. Для теста добавьте минимум двух участников с разных браузеров/устройств.
7. Закройте регистрацию и запустите жеребьёвку.
8. Откройте личные ссылки и проверьте результаты.

## Важно про регистрацию без телефона
Без телефона, email или подтверждения личности нельзя надёжно доказать, что два разных устройства принадлежат одному и тому же человеку. Сейчас сайт блокирует повторную регистрацию из того же браузера по уникальному ключу браузера. Если человек очистит данные браузера или откроет другой браузер, он теоретически сможет зарегистрироваться повторно. Организатору стоит проверить список имён перед закрытием регистрации.

## Важно про личные ссылки
Личная ссылка — это секретный ключ доступа к результату. Участник должен сохранить её и никому не пересылать. Если ссылка потеряна, в текущей версии восстановить её автоматически нельзя: это сделано намеренно, чтобы организатор не мог посмотреть чужой результат.

## Ограничения первой версии
- Приглашения участникам отправляются вручную: сайт выдаёт личную ссылку участника после регистрации.
- Админ видит имена и пожелания, но не видит распределение пар.
- Технический владелец Supabase с доступом к service role и базе потенциально может изучить записи напрямую. Не обещайте абсолютную криптографическую секретность.
- Не удаляйте участников после проведения жеребьёвки: это может нарушить распределение.
